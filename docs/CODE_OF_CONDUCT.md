# Community expectations

Treat participants with respect. Discuss ideas and code constructively, welcome questions, and give actionable feedback. Harassment, threats, discriminatory abuse, and publishing private information are not acceptable.

These expectations apply to issues, pull requests, reviews, and other project community spaces. Maintainers may edit or remove harmful content and restrict participation when needed. Enforcement should account for context and repeated behavior.

Report concerns to the repository maintainer through a private contact listed on their GitHub profile. If no private contact is available, ask for one without posting personal information or incident details publicly. Security vulnerabilities follow [SECURITY.md](../SECURITY.md).
